# Objetivo
Implementar las diferentes capas necesarias para que una aplicación pueda interactuar con hardware a través del SO de forma que se fomente la creatividad en el diseño e integración de software y hardware.

# Elección Libre
En este proyecto cada quién puede elegir qué desarrollar utilizando alguna aplicación de los conceptos de SO. Las áreas que debe cubrir el proyecto son:

## 1. I/O de datos
Se debe crear un driver hecho a la medida ajeno para controlar un dispositivo de hardware externo. La recomendación es utilizar el módulo de kernel utilizando GPIO.

## 2. Hardware
Debe desarrollarse algún dispositivo electrónico que involucre algún tipo de movimiento o funcionalidad interesante de procesamiento como un procesador de video o audio por ejemplo.

## 3. Distribución
Se debe contar con procesamiento distribuido. Al menos debe contarse con 3 nodos de procesamiento, no es permitido compartir archivos directamente desde un directorio.

## 4. Seguridad
Toda información compartida por medio de red debe ser cifrada utilizando algún algoritmo criptográfico.
